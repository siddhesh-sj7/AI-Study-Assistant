About the project

What is AI Student Assistant?

AI Student Assistant is a web-based study platform designed to support school and college students with everyday learning tasks. It focuses on simple academic help instead of complicated workflows.

  • Ask doubts with the chatbot
  • Summarize notes for revision
  • Generate quizzes for practice
  • Access everything from one dashboard
Built for students

Who built it and why?

This project was created for learners who need fast, beginner-friendly support. It is a strong fit for students such as BSc IT learners who want one place for AI help, revision tools, and practice questions.

Built by Siddhesh with Codex support using HTML, CSS, JavaScript, Node.js, Express, MongoDB, and optional OpenAI-powered responses.
